# f07 · Ember & Oak Roasters — starter

An empty React app with React Router and Tailwind installed, the colours and
fonts in `src/index.css`, the coffees in `src/data/coffees.js` and their
pictures in `public/images/`. You build the site in it one step at a time
by following `../INSTRUCTIONS.md`.

```
npm install
npm run dev
```

You should see a dark page with **Ember & Oak** in large cream letters and
nothing else.
